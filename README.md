# URB

Design demo for **URB (@shop.urb)**, a Pakistani hand-tied bouquet brand. Static HTML, CSS and JavaScript: no build, no backend.

```bash
npx http-server -p 4173 .            # then open http://127.0.0.1:4173
node scripts/verify.mjs              # links, flows, overflow at 7 widths (needs Playwright)
```

- Research and gaps: [docs/RESEARCH.md](docs/RESEARCH.md)
- Tokens, laws, workflows: [docs/DESIGN-SYSTEM.md](docs/DESIGN-SYSTEM.md)
- Tokens: `css/tokens.css`. Products: `js/data.js`.

Bouquet images are generated SVG illustrations (no photos were available). Replace with real photography when supplied.
